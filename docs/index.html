01 / FIRST PRINCIPLE

简历不是一次性的文案，
而是职业证据库在特定 JD 下的一次视图生成。

02 / EVIDENCE CHAIN

五段式模型，把经历变成可验证论点

每个项目一张证据卡。工具与交付物不是结果，只有当它们连接问题、判断或验证时，才成为求职证据。

  1. 01问题原流程、目标与约束
  2. 02边界真实所有权与职责范围
  3. 03判断方案、取舍与兜底策略
  4. 04落地PRD、原型、评审与验收
  5. 05证据指标、里程碑与质量证明

03 / MODULAR CORE

一个通用内核，按 JD 组合方向模块

通用产品能力始终启用；AI、增长、数据、风控与支付能力只在目标岗位需要时进入候选池，支持自定义方向，避免"什么都写、什么都不突出"。

04 / ADMISSION GATE

不是所有素材，都应该进入简历

先处理可信度，再谈表达力。推导可以使用，但涉及指标、所有权、上线状态和业务结果的关键事实必须等待确认。

等级证据状态简历准入
S已上线＋可信结果证明核心结果
A已交付／验收＋规模或质量证明核心证据
B已评审或开发／测试中注明阶段
C完整方案、原型或 Demo明确标注
D想法、讨论或弱执行事项仅素材库

05 / GROWTH LOOP

每做完一个项目，下一份简历都会更强。

记录材料→生成证据卡→匹配 JD→投递与面试→复盘迭代
